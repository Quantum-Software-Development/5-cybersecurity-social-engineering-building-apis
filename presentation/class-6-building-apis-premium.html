Query strings and encodingQuery strings e codificação

? begins · & separates · = associates? inicia · & separa · = associa

/api/products?category=books&limit=5

A path parameter identifies a resource: /api/products/1. A query parameter can filter a collection.Um parâmetro de caminho identifica um recurso: /api/products/1. Um parâmetro de consulta pode filtrar uma coleção.

from urllib.parse import urlencode
query = urlencode({"category": "café", "limit": 5})
print(query)
# category=caf%C3%A9&limit=5

Encoding is not encryption. Never place passwords or tokens in query strings.Codificação não é criptografia. Nunca coloque senhas ou tokens em query strings.

CLASS 6 · BUILDING APIs · 10
A small Flask applicationUma pequena aplicação Flask
Save as app.py and run locally.Salve como app.py e execute localmente.
from flask import Flask, jsonify

app = Flask(__name__)

@app.get("/api/health")
def health():
    return jsonify(status="ok")

if __name__ == "__main__":
    app.run(host="127.0.0.1", port=5000, debug=False)
The decorator maps a GET request to a function. jsonify creates a JSON response. This minimal example has no authentication.O decorador associa uma requisição GET a uma função. jsonify cria uma resposta JSON. Este exemplo mínimo não tem autenticação.

import json
from pathlib import Path
import pandas as pd

source = Path(__file__).resolve().parent / "data" / "products.xlsx"
frame = pd.read_excel(source, engine="openpyxl")
required = {"id", "name", "category", "price_cents"}
if not required.issubset(frame.columns):
    raise ValueError("Missing required columns")
records = json.loads(frame.to_json(orient="records"))

CLASS 6 · BUILDING APIs · 12
Defaults are not validationValores padrão não são validação
Absent and invalid are different states.Ausente e inválido são estados diferentes.
from flask import abort, request

def read_limit():
    raw = request.args.get("limit")
    if raw is None:
        return 10
    if not raw.isascii() or not raw.isdecimal() or len(raw) > 3:
        abort(400, description="Invalid limit")
    value = int(raw)
    if not 1 <= value <= 100:
        abort(400, description="Limit must be 1 to 100")
    return value
Use this helper inside a Flask request handler. It defaults only when absent. Empty and invalid values are rejected. For a complete contract, also decide how to handle repeated and unknown parameters.Use esta função dentro de um manipulador Flask. O padrão só vale quando o parâmetro está ausente. Valores vazios ou inválidos são rejeitados. Defina também o tratamento de parâmetros repetidos e desconhecidos.
